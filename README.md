# Number Guessing Game

A terminal-based Java game developed during my first year of college (2023). Inspired by a Python Book from "Python Crash Course" by Eric Matthes, this project was my self-challenge to recreate the game in Java. It helped me transition from Python basics to core Java programming concepts like loops, input validation, and exception handling.

The game generates a random number (1-100) and provides high/low feedback for guesses. Features include attempt tracking, input error prevention, and a quit option that reveals the secret number. Built using Java's Scanner for input, Random for number generation, and basic control structures, it demonstrates early programming fundamentals.

This project taught me Java syntax, terminal I/O operations, and basic debugging techniques. To play: compile with javac NumberGuessingGame.java and run with java NumberGuessingGame.
